​As Validator

​Node.js

To use Jedison as a JSON validator, these options are required:

  • schema defines the validation rules. This is the only mandatory option when using Jedison for validation. The validator will check JSON data against this schema without needing a UI container or theme.
const Jedison = require('jedison')

const jedison = new Jedison.Create({
  schema: {
    title: 'Person',
    type: 'object',
    properties: {
      name: {
        type: 'string',
      },
      age: {
        type: 'integer',
        minimum: 0,
      }
    },
    required: [
      'name',
      'age'
    ],
  },
})

jedison.setValue({
  name: 'Alice',
  age: 30
})

console.log(jedison.getErrors())

// Valid: outputs is an empty array
// []

jedison.setValue({
  id: 123,
  price: 'free',
})

console.log(jedison.getErrors())

// Invalid: outputs is an array of errors
// [
//   {
//     type: 'error',
//     path: '#',
//     constraint: 'required',
//     messages: ['Must have the required properties: name, age.']
//   }
// ]

​JSON Schema versions

Jedison follows draft 2020-12. Schemas that declare an older $schema (draft-04, draft-06, draft-07 or 2019-09) are normalized to 2020-12 before use, so validation and forms behave the same for all of them:

  • items as array and additionalItems become prefixItems and items.
  • dependencies becomes dependentRequired and dependentSchemas.
  • Draft-04 id and boolean exclusiveMinimum / exclusiveMaximum are converted.
  • Keywords next to $ref are ignored up to draft 7. See the keepRefSiblings option.

$dynamicRef and $recursiveRef are not supported.

const jedison = new Jedison.Create({
  schema: {
    // Declare the draft the schema was written for
    $schema: 'http://json-schema.org/draft-07/schema#',
    type: 'object',
    properties: {
      // Draft 7 tuple: "items" as array + "additionalItems"
      point: {
        type: 'array',
        items: [{ type: 'number' }, { type: 'number' }],
        additionalItems: false,
      },
      card: { type: 'string' },
      billing: { type: 'string' },
    },
    // Draft 7 "dependencies"
    dependencies: {
      card: ['billing'],
    },
  },
})

jedison.setValue({ point: [1, 2, 3], card: '4111' })

console.log(jedison.getErrors())

// Errors:
// - "#"         dependentRequired: Must have the required properties: billing.
// - "#/point/2" the third item is not allowed (additionalItems: false)

// Keep keywords next to "$ref" in draft 7 and older
const other = new Jedison.Create({
  schema: { $schema: 'http://json-schema.org/draft-07/schema#', /* ... */ },
  keepRefSiblings: true,
})
